# 流式异常恢复实施记录

目标：应用级任务管理、协议结束验证、事务与周期保存、后台有限执行及启动修复。

已确认：切换会话继续生成；后台最多20秒或系统提前到期；手动重新生成；首段前保留旧回复。
默认：单会话一个任务，全局三个；每秒有变化才保存；iOS16；不引入服务端续传。

任务与接口检查：
- 网络与管理器共享 StreamChunk；协议层区分 finishReason 与 done，管理器只接受完整终态。
- 存储与管理器共享 generationID/sequence；事务开始、CAS快照及终态，拒绝旧任务写入。
- 管理器与界面共享会话快照及观察事件；界面释放不取消任务。
- 生命周期通过后台执行协议注入，不依赖终止回调。
